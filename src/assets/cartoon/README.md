# Cartoon artwork

Original artwork generated with the built-in imagegen tool on October 17, 2026,
using Jeremy's supplied Tri Towers screenshot and his approved art study as
visual references. Ranks, suits, badges and their values are live UI, not artwork.
The WebP files retain the generated dimensions and transparency (quality 90).

Tower prompt: one centered warm sandstone cylindrical castle tower, broad
crenellated turret, chunky golden-beige stones, gold medallion, narrowing shaft
and stone foot; original playful hand-painted casual-game illustration; full
silhouette, transparent background, no cards, words, numbers, sky or landscape.

Courts prompt: three equal horizontal square cells containing original Jack,
Queen and King busts in navy/red/gold; friendly illustrated faces, bold outlines,
matching framing, transparent background; no suit symbols, ranks, text or cards.
The equal-thirds atlas is clipped only during display.
